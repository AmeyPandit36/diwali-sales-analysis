# Diwali Sales Data Analysis

A comprehensive data analysis project exploring sales patterns and trends during the Diwali shopping season. This project demonstrates essential data science techniques including data cleaning, exploratory data analysis (EDA), and data visualization.

## 📋 Overview

This project performs in-depth analysis on Diwali sales data to uncover meaningful patterns and insights. Through systematic data cleaning and exploratory analysis, we identify key trends across demographics, geography, and product categories.

## 🎯 Objectives

- Clean and preprocess raw sales data for accurate analysis
- Explore demographic patterns in customer purchasing behavior
- Identify top-performing regions and product categories
- Analyze sales trends across different customer segments
- Generate actionable business insights for decision-making

## 📊 Key Insights

- **Gender Analysis**: Total sales segmented by customer gender demographics
- **Age Group Trends**: Sales patterns across different age groups
- **Geographic Performance**: Top states and regions by sales volume
- **Occupation Insights**: Sales analysis by customer occupation
- **Product Categories**: Category-wise sales distribution and performance metrics
- **Customer Behavior**: Purchasing patterns and preferences

## 🛠️ Skills Demonstrated

- **Data Loading & Inspection**: Loading datasets and understanding structure
- **Data Cleaning**: Handling inconsistencies and standardizing data formats
- **Missing Value Treatment**: Strategies for handling incomplete data
- **Data Transformation**: Feature engineering and data restructuring
- **Aggregation & Grouping**: GroupBy operations and statistical summaries
- **Sorting & Filtering**: Data subsetting and ranking
- **Exploratory Data Analysis**: Identifying patterns and correlations
- **Data Visualization**: Creating meaningful visual representations

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook
- Required libraries (see installation below)

### Installation

```bash
# Clone the repository
git clone https://github.com/AmeyPandit36/diwali-sales-analysis.git

# Navigate to the project directory
cd diwali-sales-analysis

# Install required dependencies
pip install pandas numpy matplotlib seaborn jupyter

# Start Jupyter Notebook
jupyter notebook
```

## 📖 Usage

1. Open the Jupyter Notebook files in the repository
2. Execute cells sequentially to view the analysis pipeline
3. Examine visualizations and insights generated at each step

## 📈 Analysis Pipeline

1. **Data Loading**: Import raw sales data
2. **Data Inspection**: Understand structure, types, and dimensions
3. **Data Cleaning**: Handle missing values, duplicates, and inconsistencies
4. **Exploratory Analysis**: Statistical summaries and distributions
5. **Aggregations**: Compute group-wise statistics and totals
6. **Visualization**: Create charts and plots for insights
7. **Insights Generation**: Draw conclusions and recommendations

## 💡 Key Findings

This analysis reveals important patterns in Diwali shopping behavior:
- Customer preferences vary significantly by demographic factors
- Certain regions and product categories drive disproportionate sales
- Seasonal shopping patterns align with traditional festivities
- Occupation and age group are strong indicators of purchasing behavior
